# DynIsl — Dynamic Island для Windows 10/11 🏝️✨

Премиальный, эргономичный и ультраплавный **Dynamic Island** для Windows, созданный с эстетикой и физикой Apple iOS, поддержкой эффекта «капельки» (SVG Gooey Droplet Physics), синхронизированным текстом песен (караоке), буфером обмена (Win+V), вторым островком для звонков Discord/Telegram и полкой поглощения файлов.

---

## 🌟 Основные возможности

### 1. 💧 Физика капельки и крепление к верхней грани (Liquid Droplet)
- Динамический остров физически соединен с верхней гранью монитора специальным жидким мостиком («капелькой»).
- При раскрытии, сворачивании и перетаскивании файлов воспроизводятся реалистичные анимации поверхностного натяжения с использованием SVG metaball-фильтров и пружинных кривых `cubic-bezier`.
- Автоматически центрируется по верхней кромке любого монитора (1080p, 1440p, 4K, UltraWide).
- Прозрачные области окна на 100% пропускают клики мыши сквозь себя (Pass-through click), не блокируя рабочий стол и приложения.

### 2. 🎵 Плеер любого источника + синхронизированные слова (Караоке)
- Поддержка воспроизведения из **Spotify, Яндекс Музыки, YouTube, Chrome, Edge, Apple Music, VLC** через официальный Windows GSMTC WinRT API.
- **В покое:** если играет музыка — живой органический эквалайзер. При паузе/остановке — эквалайзер плавно засыпает в режим покоя.
- **В раскрытии:** обложка альбома с неоновым свечением, название трека, исполнитель, интерактивный ползунок перемотки, кнопки Play/Pause, Next, Prev.
- **Синхронизированный текст песен (Karaoke LRC):** встроенный движок караоке через LRCLIB автоматически находит слова песни, плавно скроллит активную строчку и подсвечивает её. Клик по любой строчке мгновенно перематывает песню на эту секунду!

### 3. 📞 Второй островок для звонков (Discord & Telegram)
- При голосовом вызове рядом с основным островом отпочковывается **второй мини-островок** с эффектом капли.
- **Индикатор активации голоса Discord:** вокруг иконки горит и пульсирует зеленый кружок, реагирующий на громкость речи в микрофон в реальном времени (CoreAudio API).
- Таймер длительности разговора (`04:15`).
- **Кнопка аппаратного мута микрофона:** реально глушит и включает микрофон в системе Windows!

### 4. 🔤 Умный автопереключатель раскладки (Punto Switcher)
- Распознает ввод русского текста на английской раскладке (например, `ghjtrn` → `проект`, `ghbdtn` → `привет`, `dctv` → `всем`, `rfr ltkf` → `как дела`).
- Автоматически заменяет слово через низкоуровневый хук и показывает элегантное уведомление на острове.

### 5. 📋 Интегрированный буфер обмена (Win+V / Alt+V)
- Полная замена стандартного всплывающего окна Windows.
- Остров плавно вытягивается сверху в виде аккуратного меню с историей текстов, сниппетов и изображений.
- Поиск по тексту, закрепление (Pin), удаление и вставка в один клик.

### 6. 📁 Полка поглощения файлов (Drag & Drop)
- Перетащите любой файл на Dynamic Island — остров среагирует магнитным притяжением и плавно поглотит файл анимацией «капельки».
- Файл сохраняется на полке для быстрого доступа.
- Быстрые действия: отправка в **Telegram**, отправка в **Discord**, копирование файла в буфер обмена Windows, открытие в проводнике или закрепление.

### 7. 🔔 Уведомления из соцсетей (Telegram, Discord, VK)
- Всплывающие карточки с аватарками, значками соцсетей, текстом сообщения и кнопками быстрого ответа прямо внутри Dynamic Island.

### 8. 🎮 Автоскрытие в играх и полноэкранных приложениях
- Фоновый монитор окон Win32 определяет запуск игры или видео на весь экран и плавно прячет остров за верхнюю кромку монитора, чтобы не закрывать интерфейс игры.
- При выходе из игры остров возвращается.
- Горячая клавиша принудительного скрытия/показа: `Ctrl + Shift + H`.

### 9. 🎨 Настройки прямо внутри острова (Никаких сторонних окон!)
Все настройки открываются прямо внутри Dynamic Island:
- **Глубокий чёрный (OLED)** — каноничный стиль iPhone Dynamic Island.
- **Liquid Glass (Жидкое стекло)** — эффект акрила/слюды с 45px blur, преломлением и бликом сверху.
- **Живой градиент (Fluid Aurora)** — космический переливающийся градиент.
- **Кастомный цвет** — выбор любого оттенка фона и акцента.
- Настройка формата времени и даты в покое.
- Тестирование звонка и уведомлений.

## 🚀 Запуск проекта

### Быстрый запуск (1 клик):
Дважды щелкните по файлу **`start.bat`** в папке `D:\Projects\dynisl`.

### Запуск через терминал:
```cmd
cd /d D:\Projects\dynisl
npm start
```

## 🛠️ Архитектура

- **Frontend:** React 19, Vite, Lucide Icons, Hardware-Accelerated CSS Transitions & Springs, SVG Metaball Gooey Filter.
- **Desktop Shell:** Electron 45 (frameless, transparent, always-on-top, dynamic bounds mouse passthrough).
- **Core Native Service (`DynislCore.exe`):** C# .NET 8 (Windows 10/11 WinRT GSMTC Media Session, Win32 Low-Level Keyboard Hook, Win32 Clipboard Listener, CoreAudio IMMDevice COM API, Fullscreen Window Detector).
